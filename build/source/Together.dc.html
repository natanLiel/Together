Where this differs from the spec

Built on the Together kit, restyled to the agreed system — plum-black #14101A ground, rose #E0759A, light rose #F0A8C2, plum #B07AC8. Instrument Serif throughout, all interface copy lowercase, her words in italic. The primary gradient is reserved for the one main action on a screen. Blush #B66A5A, dusty rose #C9A8A8. The wordmark and app icon are your artwork, placed unaltered, ink #252323 for the match moment. Type stays Caprasimo over Figtree per the bound system.

Destructive actions use the dark neutral rather than an invented red, always with an explicit verb so colour is never the only signal.
